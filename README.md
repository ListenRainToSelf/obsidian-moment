# 此刻 MOMENT · Obsidian 朋友圈式日记插件

> 把日记写成像发「朋友圈」一样自然：碎片、即时、带着氛围感。

「此刻 MOMENT」是一款 Obsidian 第三方插件，把写日记从一个「写作任务」改写为「发一条动态」。单条记录不必成文——一个词、一张图、一句牢骚都是合法内容；界面是仿朋友圈的双视图（信息流 + 下拉全览），读起来轻松，回看起来也充满成就感。

**数据永远在本地的原则**：所有记录都落成标准 markdown 与普通图片附件，任何编辑器都能打开、修改、删除。插件只是「读写它们」，不是「占有它们」。

---

## 项目结构

```
obsidian-moment/
├── manifest.json          # 插件元信息 / id / minAppVersion
├── package.json           # 依赖与构建脚本
├── tsconfig.json          # TypeScript 配置
├── esbuild.config.mjs     # esbuild 打包配置
├── src/
│   ├── main.ts            # Plugin 入口，注册视图与命令，轮询心跳
│   ├── settings.ts        # 设置面板：可配置根目录/命名规则/签名/名言
│   ├── view.ts            # ItemView：封面 + 活跃度 + 信息流 + 下拉全览
│   ├── overview.ts        # 下拉全览：按天/周/月/年聚合
│   ├── cover.ts           # 背景(附件 img.jpg)自动加载
│   ├── dayFile.ts         # 日期文件读写 / frontmatter / 追加
│   ├── activityGrid.ts    # 活跃度格点统计与渲染
├── styles.css             # 界面样式与动效
└── main.js / manifest.json # 构建产物（复制进 vault 插件目录即可用）
```

## 项目使用技术

- **语言**：TypeScript
- **构建**：esbuild（官方 Build a plugin 起手式）
- **平台 API**：Obsidian Plugin API（`Plugin` / `ItemView` / `Vault` / `MetadataCache` / `Workspace`）
- **数据格式**：属主 markdown（YAML frontmatter + `## 时间` 标题块）+ 普通图片附件
- **存储**：纯本地（Vault 文件系统），无需任何云端

## 完整功能

| 模块 | 说明 |
| ---- | ---- |
| 背景 + 签名 | 附件目录放入 `img.jpg` 即自动加载为新背景；签名为一句短文案，居背景右下角 |
| 快速发布（右上角 `＋`）| 输入文字、选心情、可配图；`Enter` 发送、`Shift+Enter` 换行；配图按时间命名落入附件夹 |
| 活跃度格点 | 每格代表一天，颜色随条数渐进加深，构成封面的情绪刻度 |
| 朋友圈信息流 | 倒序消息，每条仅「发布时间 + 心情」两处强制标记，内容自然流淌 |
| 下拉全览 | 页面顶端下拉带阻尼，越过阈值进入相册式聚合视图；按天/周/月/年四档切换，再次下拉返回 |
| 心情统计 | 鼠标悬停封面时，底部渐变模糊层从下上滑，显示最近 30 天各心情次数与占比（进度条） |
| 背景高度段 | 共 7 档，可设置封面包裹背景图片显示第几段（顶→底）；鼠标悬停封面时整图展开 |
| 心情候选 | 设置面板可自由添加 / 删除发动态时可选的心情 |
| 每日名言 | 灰分界线 + 名言，区分活跃度与信息流（随机 / 自定义） |
| 轮询 + 事件监听 | 订阅 vault 改动即时通知，30s 心跳兜底外部改动 |
| 设置面板 | 可配置根目录（绝对/相对路径）、命名规则、签名、名言池 |

## 安装使用方法

### 1. 构建插件

本仓库为源码工程。请在根目录执行：

```bash
npm install        # 安装依赖（拉取失败时使用镜像源：npm config set registry https://registry.npmmirror.com）
npm run build      # 构建，产物为 main.js
```

### 2. 安装到 Obsidian

构建完成后，将 `main.js`、`manifest.json`、`styles.css` 三个文件复制到 Obsidian 的插件目录：

```
您的库路径/.obsidian/plugins/obsidian-moment/
```

然后在 Obsidian「设置 → 第三方插件」中启用「此刻 MOMENT」。

### 3. 使用

- 在左侧栏点击「此刻」图标（或执行命令「此刻 MOMENT：打开朋友圈」）打开视图。
- 首次使用请在「设置 → 此刻 MOMENT」中配置根目录（库内相对路径），如 `日记`。
- 向 `附件` 目录放入 `img.jpg` 即可更换朋友圈背景。
- 点击顶部背景右上角的圆形「＋」快速发布一条动态。

> 完整的人工验收清单见 [TEST.md](TEST.md)（发布→读回、背景、下拉全览、聚合、外部改动同步等）。

### 数据文件规范（默认）

```
# 根目录
├── 附件
│   ├── img.jpg                  # 朋友圈背景（固定名）
│   └── 2026-9
│       └── 2026-9-10-18:58:30.jpg   # 按时间命名的附件
└── 2026-9
    └── 2026-9-10.md             # 按天命名的正文（mood/quote 在 frontmatter）
```
